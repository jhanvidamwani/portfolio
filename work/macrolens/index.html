MacroLens

Reading markets through prediction markets.

Role

Research and analysis

Built with

Next.js, Supabase, GitHub Actions, Regression

GitHub

The problem

Prediction markets like Kalshi put a live price on macro events, but those odds rarely get connected to what they mean for the wider economy.

What I built

MacroLens is a live view of Kalshi prediction-market data, with regression and cross-asset scenarios that show how market expectations connect to equities, rates and commodities.

How it works

  1. 1

    Ingest

    Scheduled jobs pull live Kalshi prices into a database.

  2. 2

    Model

    Regressions relate shifts in event odds to moves in other assets.

  3. 3

    Explore

    Scenario views show how a change in odds could ripple outward.

What it shows about how I work

  • I think about events as probabilities, not headlines.
  • I connect a niche data source to questions people already care about.
  • I make abstract data legible through scenarios.
