The problem

Different AI models are good at different things, and switching between them all day wastes time and loses context.

What I built

Vault is an agentic platform that routes each task to the right model and keeps one shared memory of your work in pgvector. A Barclays Managing Director uses it daily.

How it works

  1. 1

    Ask

    You bring a task into one workspace, not five tabs.

  2. 2

    Route

    Vault sends it to the model best suited for it: Claude, GPT-4o or Gemini.

  3. 3

    Remember

    Project context is stored as vectors, so every model answers with the same memory.

What it shows about how I work

  • I spot a daily workflow pain and design the product around it.
  • I build with current model APIs, not just chat windows.
  • I ship something a senior banker chooses to use every day.
