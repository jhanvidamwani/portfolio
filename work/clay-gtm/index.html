Clay GTM Pilots

Outreach that doesn't sound like AI.

Clay GTM PilotsThe storyp. 21

The problem

Most AI-written outreach is generic, and prospect lists go stale fast.

“I can take a growth workflow from idea to running pipeline.”

What I built

Two outreach pipelines that find prospects, enrich them with LinkedIn and company signals, and write personalized messages. I wrote rules to stop the AI sounding generic and debugged the real failures along the way, from input size limits to model settings.

How it works

  1. 1Find

    Source prospects through API-based search.

  2. 2Enrich

    Add LinkedIn and company tech-stack signals to every record.

  3. 3Write

    Generate copy with conditional rules that ban generic phrasing.

Built with

  • Clay
  • API enrichment
  • Prompt engineering
